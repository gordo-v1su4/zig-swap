# v0 demo scope

v0 is done when one bundled clip plays through the full stack with both manual scrub and automatic grid chop/stutter on a running locked clock from pre-baked beat JSON.

Manual scrub alone does not prove the platform — Time Shaper's bar is audio-parity steering. Prep scripts (Essentia) can land after the PGM loop closes; v0 ships with bundled sample clip + JSON.
